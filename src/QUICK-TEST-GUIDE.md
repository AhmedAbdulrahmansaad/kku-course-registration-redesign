# ⚡ **دليل الاختبار السريع**

## 🎯 **اختبر كل شيء في 5 دقائق!**

---

## ✅ **الاختبار 1: تسجيل الدخول والخروج**

### **الخطوات:**
```
1. افتح النظام
2. اضغط "إنشاء حساب"
3. املأ البيانات:
   - الاسم: أحمد محمد
   - الرقم: 442011111
   - البريد: test1@kku.edu.sa
   - المرور: Test@123
   - الدور: طالب

4. سجل الدخول
   ← تم التحويل للصفحة الرئيسية ✅

5. انظر للـ Header
   ← اسمك موجود ✅
   ← "طالب" ظاهر ✅
   ← زر "خروج" موجود ✅

6. اضغط "خروج"
   ← رسالة: "تم تسجيل الخروج" ✅
   ← العودة لصفحة التعهد ✅
```

**النتيجة المتوقعة:** ✅ **كل شيء يعمل**

---

## ✅ **الاختبار 2: التحويل حسب الدور**

### **أ. حساب مشرف:**
```
1. أنشئ حساب جديد
   - الدور: مشرف أكاديمي

2. سجل الدخول
   ← تم التحويل للوحة المشرف مباشرة ✅
   ← رسالة: "تم تحويلك إلى لوحة المشرف" ✅

3. انظر للـ Navigation
   ← "لوحة المشرف" موجودة ✅
```

### **ب. حساب طالب:**
```
1. سجل دخول بحساب طالب

2. انظر للـ Navigation
   ← "لوحة المشرف" غير موجودة ✅

3. حاول الدخول للوحة المشرف
   ← ممنوع ✅
```

**النتيجة المتوقعة:** ✅ **التحويل يعمل + الحماية تعمل**

---

## ✅ **الاختبار 3: التحميل بنفس اللغة**

### **بالعربية:**
```
1. النظام بالعربية
2. اذهب للجدول
3. حمّل PDF
   ← العناوين بالعربية ✅
   ← أسماء المقررات بالعربية ✅
   ← كل شيء من اليمين لليسار ✅
```

### **بالإنجليزية:**
```
1. غيّر اللغة للإنجليزية
2. اذهب للجدول
3. حمّل PDF
   ← العناوين بالإنجليزية ✅
   ← أسماء المقررات بالإنجليزية ✅
   ← كل شيء من اليسار لليمين ✅
```

**النتيجة المتوقعة:** ✅ **اللغة متطابقة**

---

## ✅ **الاختبار 4: خيارات التحميل**

### **الخطوات:**
```
1. اذهب للجدول الدراسي
2. اضغط "تحميل PDF"
   ← نافذة الطباعة تفتح ✅
   ← جدول منسق ✅

3. اضغط "طباعة"  
   ← التنسيق احترافي ✅
   ← شعار الجامعة موجود ✅
   ← معلوماتك موجودة ✅
```

**النتيجة المتوقعة:** ✅ **التحميل يعمل بشكل مثالي**

---

## ✅ **الاختبار 5: معلومات المستخدم**

### **الخطوات:**
```
1. سجل دخول
2. انظر للـ Header (أعلى الصفحة)

يجب أن ترى:
┌─────────────────────┐
│ 👤 اسمك           │
│    دورك           │
└─────────────────────┘

3. على الجوال
   ← المعلومات تختفي ✅
   ← يظهر فقط زر الخروج ✅
```

**النتيجة المتوقعة:** ✅ **المعلومات ظاهرة وواضحة**

## 🚨 **ماذا لو وجدت مشكلة؟**

### **المشكلة: "زر الخروج غير موجود"**
```
✓ تأكد من تسجيل الدخول أولاً
✓ انظر للزاوية اليمنى العليا
```

### **المشكلة: "التحميل بلغة مختلفة"**
```
✓ غيّر لغة النظام قبل التحميل
✓ اللغة المعروضة = لغة التحميل
```

### **المشكلة: "أرى لوحة المشرف وأنا طالب"**
```
✓ تحقق من دورك في Header
✓ سجل خروج وسجل دخول بحساب طالب
```
